# Granja de Medianoche

Prototipo web de un juego 2D de granja inspirado en la idea de una experiencia por casillas, directa y rapida:

- Arar, plantar, regar y cosechar en una grilla 2D.
- Comprar semillas, gallinas y vacas con monedas.
- Resistir oleadas nocturnas de matones.
- Ganar monedas por combate y por produccion de la granja.

## Como abrirlo

Abre `index.html` en el navegador.

## Como se juega

1. Elige una herramienta: `Arar`, `Plantar`, `Regar` o `Cosechar`.
2. Haz click en las casillas de la huerta para trabajar la tierra.
3. Cada accion consume tiempo.
4. Cuando se llena el reloj, llega la noche y aparecen matones.
5. Derrotalos para ganar monedas.
6. Usa la tienda para comprar mas semillas y animales.
7. Al descansar comienza un nuevo dia y los animales producen.

## Idea de evolucion

- Añadir personaje movible por teclado.
- Incluir mas tipos de cultivos y estaciones.
- Crear estructuras defensivas para la noche.
- Guardar partida automaticamente.
